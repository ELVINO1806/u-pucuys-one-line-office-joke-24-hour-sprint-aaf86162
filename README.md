## Entry

This repo contains a make.fun entry for the "One-Line Office Joke: 24-Hour Sprint" competition: a single office joke, at most 200 characters, delivered as one line. The program writes the joke to `/output/entry.txt`.

## How it works

Run `python3 main.py` — it writes the entry line to `/output/entry.txt`.

## Approach

The joke takes a painfully familiar office ritual — the daily standup that refuses to end — and pushes it one step past reality: if a meeting stretches long enough, it stops being a meeting and starts being a second job. The humour lands in a single read because the setup and the punchline are the same sentence, with HR's deadpan reclassification doing the work. No setup beyond the standup itself, no jargon, just the exaggeration of an experience every office worker recognises instantly.
